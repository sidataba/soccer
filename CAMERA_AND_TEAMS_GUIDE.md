## 📷 Camera System

### Overview

The game now features **6 different camera modes** with smooth transitions, giving you complete control over your viewing experience!

---

### 🎥 Camera Modes

#### 1. **Top-Down** (Classic)
**Best for:** Strategic play, seeing the whole field

- Pure overhead view at 90° angle
- Height: 15 units
- Field of view: Maximum
- Perfect for beginners
- Traditional soccer game view

**When to use:**
- Learning the game
- Analyzing team positions
- Strategic planning
- Local multiplayer with many players

---

#### 2. **Isometric** (FIFA Classic)
**Best for:** Balanced gameplay, FIFA feel

- Angled view at 45°
- Height: 12 units
- Classic FIFA perspective
- Great compromise between strategy and action
- Most popular mode

**When to use:**
- Competitive matches
- Single player campaigns
- When you want that authentic FIFA feeling
- Streaming/recording gameplay

---

#### 3. **Side View** (Retro)
**Best for:** Arcade feel, nostalgic gameplay

- Side perspective at 30° angle
- Height: 8 units
- Retro arcade soccer style
- Unique gameplay experience
- Great for 1v1 matches

**When to use:**
- Casual play
- Nostalgic gaming sessions
- When you want something different
- Party mode

---

#### 4. **Follow Ball** (Dynamic)
**Best for:** Action-focused gameplay, streaming

- Camera follows the ball automatically
- Dynamic positioning
- Never miss the action
- Cinematic feel
- Great for spectating

**When to use:**
- Watching AI vs AI
- Recording highlights
- Following intense action
- Single player mode

---

#### 5. **Broadcast** (TV Style)
**Best for:** Realistic TV-like experience

- FIFA broadcast camera angle
- Height: 10 units, 35° angle
- Professional TV broadcast feel
- Fixed position with good overview
- Tournament-ready

**When to use:**
- Competitive matches
- Tournaments
- When showcasing skills
- Professional play

---

#### 6. **Pro Stadium** (Elite)
**Best for:** Immersive professional experience

- Dynamic tracking of ball position
- Adjusts to game action
- Professional stadium camera
- Smooth movements
- Most advanced mode

**When to use:**
- High-level competitive play
- Esports matches
- Professional tournaments
- Showing off to friends

---

### 🎮 Camera Controls

#### Keyboard:
- **V** or **C** key: Cycle through camera modes
- **R**: Reset camera position/zoom
- **Arrow Keys**: Pan camera (if enabled)
- **Mouse Wheel**: Zoom in/out
- **Page Up/Down**: Zoom in/out

#### Gamepad:
- **D-Pad Up**: Next camera mode
- **D-Pad Down**: Previous camera mode
- **Right Stick**: Pan camera
- **R3 (Click Right Stick)**: Reset camera

#### UI Controls:
- Click camera mode buttons in UI
- Use dropdown menu for direct selection
- Toggle panning on/off
- Reset button

---

### ⚙️ Camera Settings

**Zoom:**
- Min Zoom: 5 units (close-up)
- Max Zoom: 20 units (far out)
- Zoom Speed: Adjustable

**Panning:**
- Pan Speed: Configurable
- Pan Limits: ±15 units (X), ±10 units (Y)
- Can be enabled/disabled

**Transition:**
- Smooth interpolation between modes
- Speed: 5 units/second (default)
- No jarring cuts

**Camera Shake:**
- Goal scored: Medium intensity
- Collisions: Light shake
- Special events: Custom intensity

---

### 📊 Camera Tips & Tricks

**For Better Gameplay:**
1. Start with Isometric - easiest to learn
2. Switch to Top-Down for strategy
3. Use Broadcast for competitive play
4. Follow Ball mode for AI matches
5. Pro Stadium for the "wow" factor

**For Streaming:**
1. Broadcast mode looks most professional
2. Follow Ball keeps action centered
3. Pro Stadium for dynamic feel
4. Switch modes during replays
5. Use zoom for dramatic moments

**For Local Multiplayer:**
1. Top-Down gives everyone equal view
2. Isometric is fair for all players
3. Avoid Follow Ball (can disorient)
4. Keep zoom consistent
5. Disable panning during matches

## 👥 Team Builder System

### Overview

Create your **own custom teams** with unique names, colors, formations, and player rosters!

---

### ⚽ Team Customization

#### Team Identity

**Team Name:**
- Max 30 characters
- Unique name for your squad
- Appears on jerseys and scoreboards
- Automatically generates abbreviation

**Team Abbreviation:**
- 2-3 letter code
- Auto-generated from team name
- Used in compact displays
- Can be customized

**Colors:**
- **Primary Color**: Main jersey color
- **Secondary Color**: Accent/trim color
- **Goalkeeper Color**: GK jersey (optional)
- Full RGB control (16.7 million colors!)

---

### 📋 Player Roster Management

Each team has **11 players:**

1. **1 Goalkeeper (GK)**
2. **4 Defenders (DEF)**
3. **4 Midfielders (MID)**
4. **2 Forwards (FWD)**

**Player Attributes:**
- **Name**: Customizable
- **Jersey Number**: 1-99
- **Position**: GK, DEF, MID, FWD
- **Overall Rating**: 1-99 (calculated from attributes)

**Player Stats (1-99 each):**
- ⚡ **Speed**: Running pace
- 🎯 **Shooting**: Shot power & accuracy
- 📤 **Passing**: Pass accuracy
- 🎨 **Dribbling**: Ball control
- 🛡️ **Defending**: Defensive ability
- 💪 **Physical**: Strength & stamina

---

### 🎯 Formations

**Available Formations:**

#### 1. **4-4-2** (Balanced)
Classic formation with balance between attack and defense.
```
        FWD    FWD
   MID   MID   MID   MID
   DEF   DEF   DEF   DEF
            GK
```
- **Best for**: Beginners, balanced play
- **Strength**: No weaknesses
- **Weakness**: No particular strengths

#### 2. **4-3-3** (Attacking)
Offensive formation with 3 forwards.
```
     FWD    FWD    FWD
       MID   MID   MID
   DEF   DEF   DEF   DEF
            GK
```
- **Best for**: Aggressive players
- **Strength**: Strong attack
- **Weakness**: Vulnerable midfield

#### 3. **3-5-2** (Midfield Control)
Dominates the midfield.
```
        FWD    FWD
 MID  MID  MID  MID  MID
     DEF   DEF   DEF
            GK
```
- **Best for**: Possession play
- **Strength**: Midfield dominance
- **Weakness**: Weak defense

#### 4. **5-3-2** (Defensive)
Solid defensive formation.
```
        FWD    FWD
       MID   MID   MID
  DEF  DEF  DEF  DEF  DEF
            GK
```
- **Best for**: Counter-attacking
- **Strength**: Strong defense
- **Weakness**: Lack of forwards

#### 5. **4-2-3-1** (Modern)
Modern tactical setup.
```
           FWD
     MID   MID   MID
         MID   MID
   DEF   DEF   DEF   DEF
            GK
```
- **Best for**: Flexible play
- **Strength**: Adaptable
- **Weakness**: Complex

#### 6. **3-4-3** (Ultra Attacking)
All-out attack formation.
```
     FWD    FWD    FWD
   MID   MID   MID   MID
     DEF   DEF   DEF
            GK
```
- **Best for**: High-risk, high-reward
- **Strength**: Maximum attack
- **Weakness**: Vulnerable defense

### 💾 Save/Load System

**Automatic Saving:**
- Teams saved to JSON file
- Location: `Application.persistentDataPath/teams.json`
- Auto-save on exit
- Manual save option available

**What Gets Saved:**
- Team names & colors
- All player data
- Formations
- Statistics (games, goals, etc.)
- Custom teams created

**Loading:**
- Automatic on game start
- Restores last session
- Preserves all customization

### 📚 API Reference

**TeamData:**
```csharp
// Create team
TeamData team = new TeamData("My Team", Color.red);

// Customize
team.teamName = "New Name";
team.formation = FormationType.Formation_4_3_3;
team.primaryColor = Color.blue;

// Get stats
int points = team.GetTotalPoints();
float winRate = team.GetWinPercentage();
int goalDiff = team.GetGoalDifference();

// Record result
team.RecordMatchResult(won: true, draw: false, goalsFor: 3, goalsAgainst: 1);
```

**TeamBuilder:**
```csharp
// Get instance
TeamBuilder builder = TeamBuilder.Instance;

// Get teams
TeamData team1 = builder.GetTeam1Data();
TeamData team2 = builder.GetTeam2Data();

// Customize
builder.CustomizeTeamName(team1, "New Name");
builder.CustomizeTeamColors(team1, Color.red, Color.white);
builder.SetFormation(team1, FormationType.Formation_4_3_3);

// Save/Load
builder.SaveTeams();
builder.LoadTeams();
```

**CameraController:**
```csharp
// Get instance
CameraController camera = CameraController.Instance;

// Change mode
camera.SetCameraMode(CameraMode.Broadcast);
camera.CycleCamera();

// Control
camera.ResetCamera();
camera.EnablePanning(true);
camera.ShakeCamera(intensity: 0.5f, duration: 0.3f);

// Query
CameraMode current = camera.GetCurrentMode();
```

### 🐛 Troubleshooting

**Camera Issues:**

**Problem:** Camera won't switch modes
**Solution:** Check if CameraController exists in scene

**Problem:** Camera is too close/far
**Solution:** Adjust zoom with mouse wheel or settings

**Problem:** Can't pan camera
**Solution:** Toggle panning in UI or press P key

**Team Builder Issues:**

**Problem:** Teams not saving
**Solution:** Check write permissions for save file location

**Problem:** Colors not applying
**Solution:** Ensure TeamBuilder integration is enabled in PlayerSpawner

**Problem:** Formation not working
**Solution:** Make sure spawn points are properly configured
